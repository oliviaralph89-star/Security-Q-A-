# Security-Q-A-
Section 1.1: Security Controls
Categories: Managerial, Operational, Technical, Physical.

Types: Preventive, Deterrent, Detective, Corrective, Compensating, Directive.

Flashcard Practice:

Q: What type of control is a "Warning Sign"?

A: Deterrent. It discourages an action.

Section 1.2: Fundamental Concepts
CIA Triad: Confidentiality, Integrity, and Availability.

Non-Repudiation: Provided by hashing and digital signatures to prove origin and integrity.

Zero Trust: A strategy that increases data security by assuming the network is already hostile.
